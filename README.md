# Portfolio Website

A modern, responsive portfolio web application built using **Python**, **Django**, and **Tailwind CSS**.

## Features

- Dynamic Home Page
- About Section
- Skills Management
- Projects Showcase
- Project Detail Pages
- Journey Timeline
- Certificates Gallery
- Contact Form
- Django Admin Panel
- Responsive Design

## Tech Stack

- Python
- Django
- Tailwind CSS
- SQLite
- HTML5
- CSS3

## Installation

```bash
git clone https://github.com/your-username/PortfolioWebsite.git
cd PortfolioWebsite

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000
```
